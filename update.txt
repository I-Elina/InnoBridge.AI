**PROJECT: InnovateFeed — Role-Aware AI Innovation Discovery Platform**

**What it is:**
An AI-powered platform that automatically pulls research papers, technical news, and project ideas, then converts them into structured, personalized summaries and buildable project blueprints for students. It's not a chatbot — it's a proactive innovation feed.

**Core Novelty:**
1. Role-aware personalization — content depth adapts based on user's designation (school/college/professional), skill level, and interests
2. Research-to-project translation — papers get converted into simplified explanation + project idea + tech stack + roadmap + difficulty score
3. Structured multi-layer summaries — every paper gets a 1-min overview, 5-min breakdown, and deep dive
4. Semantic search using embeddings — user profile is vectorized and matched against paper embeddings via vector similarity
5. Mini Connect feature — users interested in the same paper/project can find each other and form build teams

**Data Sources:** arXiv (research papers), GitHub Trending, Hacker News, Product Hunt

**Team:** 3 people
- Person A: Backend + Data Pipeline (arXiv ingestion, PostgreSQL, FastAPI, cron jobs)
- Person B: AI Layer (embeddings, Qdrant vector search, LLM summarization, personalization)
- Person C: Frontend (Next.js, feed UI, profile pages, Connect feature UI)

**Goal:** Full-featured semester/college project with all features including Connect

---

**TECH STACK:**
- Backend: FastAPI (Python)
- Database: PostgreSQL hosted on Supabase
- Vector DB: Qdrant (for storing and searching paper embeddings)
- Embeddings: sentence-transformers (all-MiniLM-L6-v2, runs locally, free)
- LLM: OpenAI GPT (API key ready)
- Frontend: Next.js (App Router)
- OS: Windows, using PowerShell
