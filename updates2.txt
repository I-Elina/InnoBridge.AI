===========================================================
PROJECT: InnovateFeed — Role-Aware AI Innovation Discovery Platform
===========================================================

WHAT IT IS:
An AI-powered platform that automatically pulls research papers, technical
news, and project ideas, then converts them into structured, personalized
summaries and buildable project blueprints for students. It's not a chatbot
— it's a proactive innovation feed.

-----------------------------------------------------------
CORE IDEA & USER FLOW
-----------------------------------------------------------

Step 1 — User selects a broad field (e.g. "AI", "Cloud", "Robotics")
         → Used for ingestion: we fetch papers from arXiv by this field
         → Papers are stored in PostgreSQL with embeddings in Qdrant

Step 2 — User enters a subdomain interest (e.g. "mental health with AI",
         "serverless architecture", "autonomous drones")
         → This is vectorized into an embedding
         → Semantically matched against stored paper embeddings in Qdrant
         → Only relevant papers are returned (not all papers in the field)
         → This is the core personalization: meaning-based, not keyword-based

Step 3 — User receives a personalized feed of papers with:
         → 1-min summary, 5-min breakdown, deep dive
         → Build ideas, suggested tech stack, difficulty score
         → Summaries are role-aware (adapted for school/college/professional)

Step 4 — Connect feature
         → Users interested in the same paper can find each other
         → Send collaboration requests, form build teams

-----------------------------------------------------------
CORE NOVELTY
-----------------------------------------------------------

1. Role-aware personalization — content depth adapts based on user's
   designation (school/college/professional), skill level, and interests
2. Research-to-project translation — papers converted into simplified
   explanation + project idea + tech stack + roadmap + difficulty score
3. Structured multi-layer summaries — 1-min overview, 5-min breakdown,
   deep dive for every paper
4. Semantic search using embeddings — user profile vectorized and matched
   against paper embeddings via vector similarity (not keyword search)
5. Mini Connect feature — users interested in same paper can find each
   other and form build teams

  summarizer.py using OpenAI API
  Two core functions:
  1. summarize_paper(paper, user) — for each paper: 1-min summary, 5-min

HOW THE PERSONALIZATION WORKS (THE BIG PICTURE)
-----------------------------------------------------------

1. User creates profile:
   - Broad field: "AI"
   - Subdomain interests: "mental health", "NLP", "therapy bots"
   - Designation: college student
   - Skill level: intermediate

2. Ingestion (background/cron):
   - arXiv papers fetched by broad field ("AI")
   - Each paper embedded → stored in Qdrant

3. Feed request (GET /feed/{user_id}):
   - User's subdomain interests combined into a string
   - That string embedded into a vector
   - Qdrant searches for top 20 most similar paper vectors
   - Only semantically relevant papers returned
   - Papers with no summaries get summarized by LLM (role-aware)
   - Feed returned to user

4. Result:
   - User who said "mental health AI" sees papers about affective computing,
     clinical NLP, therapy chatbots — not generic AI papers
   - Summaries are written at college student level, not PhD level

IMPORTANT NOTES
-----------------------------------------------------------

- Windows machine, use PowerShell commands
- Virtual env: backend/venv — activate with: venv\Scripts\activate
- Run server from backend/: uvicorn app.main:app --reload
- Supabase uses session pooler (port 5432), not direct connection
- All imports use app. prefix (e.g. from app.db.database import Base)
- .env must have no special characters like # in passwords
- OpenAI API key is set, Anthropic key is blank
- Qdrant cluster: us-west-1, free tier, pauses after 1 week inactivity
- Embedding model: all-MiniLM-L6-v2, vector size 384, cosine similarity
- sentence-transformers runs locally, no API key needed, completely free
