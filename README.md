# InnoBridge.AI – Frontend (MVP)

This directory contains the **frontend MVP** of the InnBridge.AI project.  
It focuses on the user interface and client-side behavior of the platform.

> Note: This frontend is currently developed and maintained as a **separate branch/component**.  
> Backend integration and unified documentation will be handled after component merging.

---

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- Node.js (for tooling and dependency management)

---

## Project Scope
- Static frontend pages
- Layout and UI structure
- Client-side scripts
- No backend/API integration at this stage

---
